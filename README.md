## Overview

Cableguys MidiShaper generates complex LFO and modulation curves from a freely drawable shape editor, sending MIDI CC or automation data to any plugin or DAW parameter in sync with the tempo.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Cableguys MidiShaper** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Drawable LFO** | Free-draw LFO shape in any curve from basic sine to complex rhythms |
| **MIDI CC Output** | Sends modulation as MIDI CC to any hardware or software target |
| **Tempo Sync** | Locks shape playback to host BPM with note division selector |
| **Multi-Shape** | Up to eight simultaneous modulation shapes on independent channels |
